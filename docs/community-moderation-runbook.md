# AI CoCreate Life 社区日常管理流程（v1.0）
更新：2026-11-16。入口：`https://www.aicocreatelife.com/community`。只供获准成人成员使用。后台：Supabase 项目 `kqjvyzousekhjdaihmnl`。

## 管理原则
- 当前规模很小：一人手工管理，不增开发、不外包。审核新会员时，先核实注册邮箱及其成人和自愿申请情况；不把活动报名用户自动导入社区。
- 不在网站前端使用 service-role/secret key。只在受控Supabase Dashboard中操作。普通成员没有管理员权限，也不通过普通用户资料提升权限。
- 若收到个人资料、账户删除、骚扰或举报，请通过公开的 `jwang1127@gmail.com` 邮箱办理；不要要求用户发送密码。可要求对方从注册邮箱回信核验。
- 仅记录必要的操作事实（日期、请求类别、处理结果），不在公开帖子披露举报者与隐私。

## A. 审核会员
1. Supabase Dashboard → Authentication → Users：确认邮箱已验证，并识别新申请。
2. Database → Table Editor → public.profiles：匹配 Users 中的用户 UUID（不是仅靠昵称）。
3. 确认符合受邀成人参与规则后，将该行 `approved` 设为 `true`；保持 `is_admin=false`、`suspended=false`。
4. 告知申请人刷新社区或重新登录，审核结果不是自动发邮件。
5. 不符合要求或身份存疑：保持 `approved=false`，必要时将 `suspended=true`。

## B. 处理违规内容
1. 举报邮件应包含帖子/评论编号、简单原因；尽量不要收集多余的私人资料。
2. 打开 Table Editor → `posts` 或 `comments`，按 `id` 找到记录核实；不得仅根据昵称认定。
3. 确认违规后，将 `status` 从 `visible` 改为 `hidden`，即时限制普通会员可见性；必要时通过受控后台删除记录。
4. 需要暂停成员时，在 `profiles` 将 `suspended` 改为 `true`，并保留必要处理记录。严重事件按适用法律和安全要求办理。
5. 现有前端没有独立审核列表；管理员使用Supabase后台，毋须赋予其他账户 `is_admin=true`。

## C. 账户信息查询、删除
1. 用注册邮箱回信核验身份；不要通过论坛帖子直接接受身份敏感请求。
2. 核对 Authentication → Users 的用户ID，以及 `public.profiles` 与帖子/评论归属。
3. 信息查询：仅向验证身份的本人提供相应资料；不要转寄其他成员的资料。
4. 删除：先明确告知“删除账户还可能删除其发布的帖子和评论及其附属讨论”；获得明确确认后，在 Authentication → Users 删除对应账户，依现有外键级联删除 `profiles`、本人帖子与评论。先核实需依法保留的部分数据及相关处理规则；不要误删其他用户。
5. 删除后核对相应会员记录不存在，并记录操作完成的时间。注销用户可能不即时使全部已签发token失效，但会员档案移除会令社区RLS拒绝访问；必要时执行会话注销。

## D. 每次活动及每周维护（5–10分钟）
- 检查待审核会员申请、举报和删除请求；对新注册用户不做自动审批。
- 观察可疑大量注册或垃圾内容；发现问题优先冻结注册/暂停账号。
- 查看Supabase和Resend额度、发信日志与Vercel异常；免费项目可能有限额、休眠或备份限制。
- 对有真实使用价值的记录归档（尊重同意和隐私）。不要把技术测试误当USPTO商标的真实商业使用证明。

## 目前安全与成本提醒
- RLS真实双账户测试已通过基本内容归属；数据库权限模拟测试通过。正式生产还需检查正确URL回跳、手机适配和至少一次密码重置。
- Supabase安全Advisor提示 `auth_leaked_password_protection`。官方文档显示该功能只在Pro及更高套餐提供；为了守住$0新增月费目标，不建议为此单项升级。应优先在免费版设置更严格密码长度、使用强密码并保持邮箱确认开启。
- 新增月费目标$0，不等于所有平台永久免费或无限量。
